# Roadmap

- **From PyPI.** appkit ships inside `omnipython-applibs`, which installs from
  TestPyPI today; `pip install omnipython-applibs` from PyPI is what's left.
- **A model for a front panel.** An app and the launcher expose a model
  (describe, apply, telemetry, command), so hmilink can serve them to a phone,
  a browser or a second screen. Apps without a model pay nothing.
